# MassBids — Massachusetts Procurement Discovery (Concept Demo)

[**Explore the interactive demo →**](https://laurenlambrecht.github.io/MassBids-Demo/)

**Think Zillow, but for local government contracts.** Public bids are fragmented across municipal websites, making it difficult for businesses to discover relevant opportunities. MassBids explores a unified, searchable discovery experience for Massachusetts government procurement.

## Try the product
- Browse **22 illustrative opportunities** from eight Massachusetts municipalities.
- Explore the clickable Massachusetts map and filter by infrastructure, technology, or services.
- Search bids by title, municipality, department, or description.
- Sort opportunities by deadline, municipality, or title.
- Open bid details for a richer project overview and estimated value.
- Save opportunities to a shortlist, persisted locally in your browser.
- Explore responsive mobile and desktop layouts.

## Product vision
In a full implementation, an ingestion pipeline could gather public procurement notices from individual municipal sources. AI-assisted extraction and classification could normalize document fields, highlight deadlines and eligibility requirements, and surface relevant matches to suppliers. **These ingestion and AI workflows are concepts, not operational integrations in this demo.**

## Tech
Static HTML, CSS, and vanilla JavaScript deployed via GitHub Pages. No login or backend required.

> **Important:** All bids, descriptions, values, and dates shown are fabricated sample data for portfolio demonstration only. No live procurement data is collected, and no bids can be submitted through this prototype.
